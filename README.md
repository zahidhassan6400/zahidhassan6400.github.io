# Zahid Hassan — Research Portfolio

This repository contains the static GitHub Pages version of Zahid Hassan's academic research portfolio.

## Publish on GitHub Pages

1. Upload **all extracted files and folders** to the root of `zahidhassan6400.github.io`.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. The portfolio will appear at <https://zahidhassan6400.github.io>.

## Update the portfolio

- Text and external links: edit `index.html`.
- Colors, spacing, and layout: edit `styles.css`.
- Portrait and logos: replace the corresponding files inside `assets/` without changing their filenames.
- Before sharing, confirm that the Google Drive CV and certification files use **Anyone with the link → Viewer** access.

Each machine-level certification badge has its own link in `index.html`, so the current shared certificate link can be replaced with a separate certificate URL later.
